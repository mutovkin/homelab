**Goal:** Replace the legacy `amdgpu-install` ROCm 7.2.2 stack inside LXC CT 201 (`n5pro_docker`) with ROCm 10.0 from AMD's new stable apt repository, with a version-aware reconcile and a real delivered-GPU assert.

**Architecture:** The Proxmox host provides the kernel driver (`amdgpu`/`kfd`, kernel 6.17.13-2-pve) and bind-mounts `/dev/dri` + `/dev/kfd` into the privileged CT — none of that changes. This change is userspace-only, inside the CT, in the `docker_host` role: a one-way migration block (runs only while legacy bits exist), the new apt repo + per-arch package, an env profile, and an assert.

**Tech Stack:** Ansible (`docker_host` role), apt/deb822, ROCm 10.0 (`amdrocm10.0-gfx1150`).

**Spec:** GitHub issue #240; session plan `/Users/surge/.claude/plans/soft-wandering-pine.md`; research report `/Users/surge/dev/rocm-10-n5pro-report-v2.md` (Part 1: gfx1150 native since ROCm 7.2 — no `HSA_OVERRIDE_GFX_VERSION`).

### Task 3: Migration block — one-way removal of the legacy amdgpu-install stack

**Files:**
- Modify: `ansible/roles/docker_host/tasks/main.yml` (replacing lines ~147–243, the whole legacy ROCm block; Tasks 3–5 together produce its successor)

**Interfaces:**
- Consumes: `gpu_sharing.enabled` gate.
- Produces: a legacy-free CT; Task 4's install assumes no `rocm.list`/`amdgpu.list` remain.

- [ ] **Step 1: Write the migration block** at the top of the new ROCm section:

```yaml
# --- ROCm userspace (AMD stable-repo channel, #240) ---
# Host provides the kernel driver + /dev/dri + /dev/kfd; this installs ONLY
# userspace. History: 7.2.2 came from the legacy amdgpu-install channel, which
# ended at 7.2.4 — the block below removes it once, then never fires again.
# The old gate (`which rocminfo`) could install but never upgrade; the new
# reconcile is apt's own version handling of the pinned package (Task 4).

- name: Probe for the legacy amdgpu-install stack
  ansible.builtin.command: dpkg-query -W -f='${Version}' amdgpu-install
  register: legacy_amdgpu_install
  changed_when: false
  failed_when: false
  check_mode: false
  when: gpu_sharing.enabled | default(false)

- name: Migrate off the legacy amdgpu-install ROCm stack (one-way, #240)
  when:
    - gpu_sharing.enabled | default(false)
    - legacy_amdgpu_install.rc == 0
  block:
    - name: Remove the legacy ROCm userspace
      ansible.builtin.command: amdgpu-uninstall -y
      register: legacy_uninstall
      changed_when: true
      # amdgpu-uninstall exits non-zero if there is nothing to remove; the
      # package probe above says there is, so a failure here is real.

    - name: Purge the legacy installer package
      ansible.builtin.apt:
        name: amdgpu-install
        state: absent
        purge: true

    - name: Remove legacy AMD repo lists
      ansible.builtin.file:
        path: "/etc/apt/sources.list.d/{{ item }}"
        state: absent
      loop:
        - rocm.list
        - amdgpu.list

    - name: Autoremove orphaned legacy dependencies
      ansible.builtin.apt:
        autoremove: true
```

- [ ] **Step 2: Sanity-gate check** — the block must be inert in check mode on an already-migrated host: the probe is `check_mode: false` so `--check` is honest; after migration `legacy_amdgpu_install.rc != 0` and the block skips. Confirm by reading the conditions once more.

```yaml
- name: Ensure apt keyring directory exists
  ansible.builtin.file:
    path: /etc/apt/keyrings
    state: directory
    mode: "0755"
  when: gpu_sharing.enabled | default(false)

- name: Download AMD ROCm stable repo signing key (armored)
  ansible.builtin.get_url:
    url: "{{ rocm_apt_key_url }}"
    dest: /etc/apt/keyrings/amdrocm.asc
    mode: "0644"
  when: gpu_sharing.enabled | default(false)

- name: Dearmor AMD ROCm signing key
  ansible.builtin.command:
    cmd: gpg --dearmor --yes -o /etc/apt/keyrings/amdrocm.gpg /etc/apt/keyrings/amdrocm.asc
    creates: /etc/apt/keyrings/amdrocm.gpg
  when: gpu_sharing.enabled | default(false)

- name: Configure AMD ROCm stable repository (deb822)
  ansible.builtin.copy:
    content: |
      X-Repo-Id: amdrocm-stable
      Types: deb
      URIs: {{ rocm_apt_repo_url }}
      Suites: stable
      Components: main
      Architectures: amd64
      Signed-By: /etc/apt/keyrings/amdrocm.gpg
      Enabled: yes
    dest: /etc/apt/sources.list.d/amdrocm-stable.sources
    mode: "0644"
  register: rocm_repo_file
  when: gpu_sharing.enabled | default(false)

- name: Install ROCm {{ rocm_release }} for {{ rocm_gfx_arch }}
  ansible.builtin.apt:
    name:
      - libatomic1
      - libquadmath0
      - "{{ rocm_package }}"
    state: present
    update_cache: true
  when: gpu_sharing.enabled | default(false)
```

### Task 5: The delivered-GPU guard

**Files:**
- Modify: `ansible/roles/docker_host/tasks/main.yml` (replacing the old `failed_when: false` rocminfo + debug pair at the end of the ROCm section)

**Interfaces:**
- Consumes: `rocm_home`, `rocm_package`.
- Produces: a hard deploy gate; Task 7 exercises both its failure modes.

- [ ] **Step 1: Write the guard** (binary path is provisional until Task 7's layout probe — see the comment):

```yaml
# The old check was `failed_when: false` + a debug message — a guard that had
# never been seen to fail, and never could. This one gates the run.
- name: Verify ROCm delivers the GPU
  ansible.builtin.command: "{{ rocm_home }}/bin/rocminfo"
  register: rocm_verify
  changed_when: false
  check_mode: false
  when:
    - gpu_sharing.enabled | default(false)
    - not ansible_check_mode

- name: Read the delivered ROCm package version
  ansible.builtin.command: dpkg-query -W -f='${Version}' {{ rocm_package }}
  register: rocm_delivered
  changed_when: false
  check_mode: false
  when:
    - gpu_sharing.enabled | default(false)
    - not ansible_check_mode

- name: Assert ROCm {{ rocm_release }} is delivered and sees {{ rocm_gfx_arch }}
  ansible.builtin.assert:
    that:
      - rocm_gfx_arch in rocm_verify.stdout
      - rocm_delivered.stdout | length > 0
    fail_msg: >-
      ROCm on this container is not delivering: rocminfo did not report
      {{ rocm_gfx_arch }} (or {{ rocm_package }} is not installed —
      dpkg says '{{ rocm_delivered.stdout | default('') }}'). If /dev/kfd is
      missing inside the CT, the host-side passthrough
      (proxmox_guests lxc-gpu-passthrough) has not run or the host needs a
      reboot; if rocminfo itself is absent, check the installed layout under
      {{ rocm_home }} — the binary path here was pinned from the live layout
      probe in #240.
    quiet: true
  when:
    - gpu_sharing.enabled | default(false)
    - not ansible_check_mode
```

- [ ] **Step 2: Commit** — `git commit -m "feat(docker_host): rocminfo delivered-GPU assert replaces the debug-only check (#240)"`
